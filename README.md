# STADEN

Staden i din ficka — en mobilförst hubb för att upptäcka kultur, nöjen, mat och platser.

Projektet är i tidig förproduktionsfas. Säkerhetskontroller som saknar appkod eller körbar målmiljö rapporteras uttryckligen som **not applicable/not executed**, aldrig som godkända tester.
